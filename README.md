All-in-one client PvP mod: health indicators, target HUD, dropped item scaler, freelook, item lock with profiles and a coords announcer.

# Features
- Health indicators on player name tags, displayed as hearts or numbers, with adjustable size, spacing, position, color, and absorption health.
- Optional health indicators for nearby mobs, with a configurable range.
- Target HUD that shows the last attacked target’s health for a configurable duration.
- Item scaling that makes selected drops larger, with per-item sizing and range settings.
- Item locks to prevent accidentally dropping selected items, with optional confirmation, visual borders, tooltips, and profiles.
- Freelook that lets you move the camera independently, with configurable view mode, sensitivity, and pitch inversion.
- One-key coordinate sharing, with a customizable message format and clipboard option.
- Optional third-person crosshair.
- In-game settings with searchable options, keybind controls, and a draggable HUD editor.
- Customizable settings-screen appearance, including accent colors, gradients, background, and UI size.
- Import and export for locked-item lists.
